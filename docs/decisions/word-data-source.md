# 단어와 뜻의 출처

## Decisions

- 게임이 쓰는 단어, 뜻풀이, 예문, 그림(이모지)은 앱에 포함된 소규모 표준어 단어장에서 가져옵니다. 외부 사전 API를 호출하지 않습니다.
- 뜻풀이는 초등학생 눈높이로 직접 다듬어 단어장에 둡니다.
- 기준 사전을 정하기 전까지 이 결정이 유효합니다.

## Boundaries

- 단어장에 없는 단어는 표준어인지와 상관없이 "사전에 없는 단어"로 처리합니다. 가까운 표준어를 제안하는 기능은 별도 작업입니다.
- 이 결정은 실제 사전을 쓰지 않겠다는 뜻이 아니라, 기준 사전을 정하기 전의 임시 출처를 정한 것입니다.

## Why

외부 사전은 인증 키, 호출 한도, 이용 약관, 브라우저 직접 호출 가능 여부가 모두 확인되지 않았거나 사용자의 가입과 발급이 필요합니다. 반면 단어장은 AI가 낼 단어, 입력 검증, 뜻 표시, 끝장단어 판정을 오프라인에서 재현 가능하게 검증할 수 있고, 초등학생에게 맞는 풀이를 직접 정할 수 있습니다.

## Reconsider when

- 제품의 기준 사전(`PRODUCT.md`의 미정 항목)이 정해질 때
- 아이가 입력한 정상적인 표준어가 단어장에 없어 자주 거부된다는 근거가 생길 때
- 인증 키 발급과 약관, 호출 한도 확인이 끝나 외부 사전을 쓸 수 있을 때

## Still-rejected alternatives

- 표준국어대사전 Open API 직접 호출: 인증 키가 필요하고 호출 한도, 이용 약관, CORS를 확인하지 못했으며 검색 응답에 예문이 없어 상세 조회를 따로 불러야 합니다. 키 발급과 약관 확인이 끝나면 다시 검토합니다.
- 네이버 사전 연동: 공식 국어사전 API를 찾지 못했고, 가장 가까운 백과사전 검색은 지식백과라 표준어 판정과 초등학생용 풀이에 맞지 않습니다. `developers.naver.com`의 현재 API 목록에서 국어사전 API가 확인되면 다시 검토합니다.
- `dict.naver.com` 화면 수집: 공식 API가 아니고 약관과 구조 변경 위험이 있습니다. 공식 제공 방식이 생기면 다시 검토합니다.

## Evidence worth preserving

- 표준국어대사전 Open API 안내 페이지: 인증 키(`key`) 필수, `req_type=json`으로 JSON 응답, 검색 응답에는 뜻풀이(`definition`)가 있고 예문은 상세 조회 API에만 있음. 호출 한도와 약관은 페이지에서 확인하지 못했습니다.
- 네이버 오픈 API 목록(`naver.github.io/naver-openapi-guide`, 오래된 가이드): 검색 API 14종에 국어사전은 없고 백과사전(`/v1/search/encyc`)만 있습니다. `developers.naver.com`은 2026-10 확인 당시 이 환경에서 열리지 않아 현재 목록은 직접 보지 못했습니다.
- 한국어기초사전 Open API: 검색 결과 기준 하루 50,000건 한도. 초등학생에게 맞는 풀이인지는 확인하지 못했습니다.
