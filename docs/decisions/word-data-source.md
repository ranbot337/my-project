# 단어와 뜻의 출처

## Decisions

- 게임이 쓰는 단어, 뜻풀이, 예문, 그림은 앱에 포함된 단어장에서 가져옵니다. 게임 중에는 외부 사전 API를 호출하지 않습니다.
- 단어장은 직접 쓴 표준어(뜻풀이를 초등학생 눈높이로 다듬고 단어별 이모지를 붙인 항목)와, 한국어기초사전의 초급·중급 명사(2–4음절)를 미리 내려받아 만든 항목으로 이루어집니다. 두 항목이 겹치면 직접 쓴 항목을 씁니다.
- 사전에서 가져온 항목의 뜻풀이와 예문은 사전 원문 그대로 쓰고, 그림은 기본 아이콘을 씁니다.
- 한국어기초사전 자료를 쓰는 곳에는 출처를 표시하고, 가공한 단어장 데이터는 같은 라이선스(CC BY-SA 2.0 KR)로 두며 앱 코드와 분리합니다.

## Boundaries

- 단어장에 없는 단어는 표준어인지와 상관없이 "사전에 없는 단어"로 처리합니다. 가까운 표준어를 제안하는 기능과 게임 중 사전 확인은 별도 작업입니다.
- 사전의 이미지, 소리, 발음 같은 멀티미디어 파일은 파일마다 이용 조건이 달라서 쓰지 않습니다.
- 한국어기초사전을 기준 사전으로 확정했다는 뜻은 아닙니다. 기준 사전(`PRODUCT.md`의 미정 항목)은 따로 정합니다.

## Why

외부 사전을 게임 중에 부르면 서버 장애와 인증 키, 호출 한도가 게임에 바로 영향을 줍니다. 한국어기초사전 서버는 개발 중에도 응답하지 않는 일이 있었습니다. 미리 내려받은 단어장은 AI가 낼 단어, 입력 검증, 끝장단어 판정을 오프라인에서 즉시 처리하고 검증할 수 있습니다. 한국어기초사전은 초급·중급 난이도 정보와 쉬운 뜻풀이가 있어 아이에게 맞는 단어를 거르기 쉽고, 텍스트 자료는 출처 표시와 동일조건 배포를 지키면 상업적 이용을 포함해 쓸 수 있습니다. 직접 쓴 단어장만으로는 단어 수가 너무 적었습니다.

## Reconsider when

- 제품의 기준 사전이 정해질 때
- 내려받은 단어장에 없는 정상 표준어가 자주 거부된다는 근거가 생길 때
- 한국어기초사전 데이터의 라이선스 해석이나 Open API 약관이 바뀌거나, 가공본을 저장하고 배포해도 되는지 문제가 생길 때
- 아이에게 적당하지 않은 단어가 자주 나온다는 근거가 생겨 난이도 기준을 바꿔야 할 때

## Still-rejected alternatives

- 게임 중 사전 API를 실시간으로 호출: 서버 장애와 한도, 속도가 게임에 직접 영향을 줍니다. 가까운 표준어 제안 기능을 만들 때 확인용으로 다시 검토합니다.
- 표준국어대사전 Open API: 난이도 필터가 없고 전문 용어와 어려운 한자어가 많으며, 검색 응답에 예문이 없습니다. 기준 사전을 다시 고를 때 검토합니다.
- 우리말샘: 비규범, 방언, 북한어가 포함되어 로블록스처럼 이상한 단어가 통하는 문제를 다시 만들 수 있습니다.
- 네이버 사전 연동: 공식 국어사전 API를 찾지 못했고, 가장 가까운 백과사전 검색은 지식백과라 표준어 판정과 초등학생용 풀이에 맞지 않습니다. `developers.naver.com`의 현재 API 목록에서 국어사전 API가 확인되면 다시 검토합니다.
- `dict.naver.com` 화면 수집: 공식 API가 아니고 약관과 구조 변경 위험이 있습니다.

## Evidence worth preserving

- 한국어기초사전 검색 API: 인증 키 필수. 응답은 XML뿐이고 `req_type=json`은 무시됩니다. 응답 항목에 뜻풀이(`definition`)와 난이도 등급(`word_grade`)이 있고 예문은 없어 상세 조회가 따로 필요합니다. 시작 글자 검색(`method=start`), 품사, 음절 수 필터가 동작했고, "사"로 시작하는 단어는 필터 없이 1,518개, 명사이면서 2–4음절이면 370개였습니다. `level` 변수는 `1`로 보냈을 때 오류 211(Invalid level value)이 나서 올바른 형식을 찾지 못했습니다. 하루 호출 한도는 50,000건입니다. 확인 중 서버가 응답하지 않거나 연결이 끊기는 일이 반복되었고, 이후 사이트 자체가 열리지 않았습니다.
- 한국어기초사전 저작권 정책(사용자가 전문을 제공): 별도 표시가 없는 텍스트 자료는 크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 라이선스로 상업적 이용을 포함해 자유롭게 이용할 수 있습니다. 조건은 저작자 표시와, 자료를 변경해 만든 새 저작물의 동일 라이선스 배포입니다. 이미지, 소리, 발음 같은 멀티미디어 파일은 파일마다 이용 조건이 따로입니다. Open API 호출 자체의 약관(호출 한도 외의 조건, 응답 저장 가능 범위)은 확인하지 못했습니다.
- 표준국어대사전 Open API 안내 페이지: 인증 키(`key`) 필수, `req_type=json`으로 JSON 응답, 검색 응답에는 뜻풀이(`definition`)가 있고 예문은 상세 조회 API에만 있음. 난이도 필터가 없습니다.
- 네이버 오픈 API 목록(`naver.github.io/naver-openapi-guide`, 오래된 가이드): 검색 API 14종에 국어사전은 없고 백과사전(`/v1/search/encyc`)만 있습니다. `developers.naver.com`은 확인 당시 이 환경에서 열리지 않아 현재 목록은 직접 보지 못했습니다.
