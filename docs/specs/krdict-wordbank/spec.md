# 한국어기초사전 단어장 확대

게임이 쓰는 단어장에 한국어기초사전의 초급·중급 명사를 더해, AI가 내는 단어와 아이가 낼 수 있는 단어를 크게 늘리는 작업입니다. 게임 규칙은 [ai-wordchain-round](../ai-wordchain-round/spec.md)가 그대로 가지고 있고, 이 문서는 그 스펙의 "단어장" 부분(단어 범위, 규모, 그림과 예문)만 바꿉니다. 앱 전체의 전제는 [PRODUCT.md](../../../PRODUCT.md), 용어는 [GLOSSARY.md](../../../GLOSSARY.md), 단어 출처에 대한 결정과 근거는 [word-data-source](../../decisions/word-data-source.md)를 따릅니다.

## 사용자에게 보이는 결과

- 게임에서 AI가 내는 단어와 아이가 입력할 수 있는 단어가 지금(355개)보다 훨씬 많아집니다.
- 사전에서 온 단어도 지금과 같은 뜻 카드로 보입니다. 단어별 이모지 대신 기본 아이콘이 나오고, 사전에 예문이 있으면 예문도 나옵니다.
- 모든 화면에 단어와 뜻풀이의 출처가 표시됩니다.
- 게임 중에는 사전 서버나 인증 키가 필요 없습니다. 내려받아 둔 데이터로 동작합니다.

## 범위

### 포함

- 한국어기초사전에서 단어와 뜻풀이, 예문을 내려받아 단어장 데이터로 만드는 방법과 그 결과물
- 기존 단어장(직접 쓴 355개)과의 합치기
- 사전 단어의 뜻 카드와 결과 화면 표시(기본 아이콘, 예문이 없을 때의 표시)
- 모든 화면의 출처 표시, 단어장 데이터의 라이선스와 출처 명시

### 제외

- 게임 중에 사전 서버로 단어를 확인하는 기능(입력한 단어 실시간 확인)
- 표준어 제안과 확인, 힌트(사전) 도우미
- 사전 단어에 단어별 이모지를 붙이는 일
- 고급 단어, 동사와 형용사 등 명사 외의 품사
- 서버, 계정, 기록의 기기 간 동기화

## 동작

### 단어장 데이터 만들기

- 한국어기초사전의 검색으로 명사이면서 2–4음절이고 난이도가 초급 또는 중급인 단어를 받는다.
- 단어마다 첫 번째 뜻풀이를 쓰고, 그 뜻의 예문을 상세 조회로 받는다. 뜻풀이와 예문은 사전 원문 그대로 쓰고 다시 쓰지 않는다. 예문이 없는 단어는 예문 없이 둔다.
- 한글이 아닌 글자가 섞인 표제어(붙임표, 숫자 등)는 뺀다. 철자가 같은 단어(동형어)는 한 번만 넣는다.
- 기존 단어장과 겹치는 단어는 기존 항목(직접 쓴 뜻풀이, 예문, 이모지)을 그대로 쓴다.
- 단어장에 넣고 싶지 않은 단어를 적어 두는 제외 목록이 있고, 목록의 단어는 다시 만들어도 들어가지 않는다.
- 같은 방법으로 단어장을 다시 만들 수 있다. 중간에 멈추면 처음부터가 아니라 이어서 받는다.
- 인증 키는 환경 변수로만 읽는다. 키와 요청 주소는 화면 출력, 로그, 저장소에 남지 않는다.
- 결과물은 앱 코드와 분리된 데이터로 두고, 각 사전 단어의 난이도 등급을 함께 보존한다.
- 결과물에는 한국어기초사전 출처와 저작자표시-동일조건변경허락 2.0 대한민국 라이선스(CC BY-SA 2.0 KR)를 읽을 수 있게 명시한다.

### 게임에서 쓰기

- 두음법칙, 끝장단어 판정, AI의 선택, 기회와 시간 제한 등 [ai-wordchain-round](../ai-wordchain-round/spec.md)의 모든 규칙을 새 단어장 전체에 그대로 적용한다.
- 사전 단어의 뜻 카드: 기본 아이콘(📖), 단어, 뜻, 예문(있을 때만 "예문:" 줄)을 보여 준다. 직접 쓴 단어는 지금처럼 단어별 이모지를 보여 준다.
- 결과 화면의 단어 목록도 같은 기준으로 보여 준다.
- 모든 화면의 아래쪽에 출처를 보여 준다. 예: "단어와 뜻풀이 일부 출처: 국립국어원 한국어기초사전 (CC BY-SA 2.0 KR)". 문구에는 라이선스 안내로 가는 링크가 있다.
- 단어장이 커져도 게임 시작이 눈에 띄게 느려지지 않아야 한다.

## 인수 기준

아래는 모두 실제로 실행해서 확인할 수 있어야 합니다.

1. 사전에서 온 모든 단어는 한글만으로 된 2–4음절이고 뜻풀이가 있으며, 보존된 난이도 등급이 초급 또는 중급이다.
2. 단어장에 같은 단어가 두 번 들어 있지 않다.
3. 기존 355개 단어가 모두 남아 있고, 뜻풀이, 예문, 이모지가 바뀌지 않았다.
4. 제외 목록에 넣은 단어는 다시 만든 단어장에 들어 있지 않다.
5. 단어장 만들기를 중간에 멈췄다가 다시 실행하면 이미 받은 부분을 다시 받지 않고 이어서 진행한다.
6. 단어장 만들기의 출력과 저장소 변경 내용에 인증 키와 요청 주소가 나타나지 않는다.
7. 인증 키가 없고 네트워크가 끊긴 상태에서도 앱이 실행되고 게임을 끝까지 할 수 있다.
8. 사전에서만 온 단어를 내면 뜻 카드에 기본 아이콘과 뜻이 보이고, 예문이 있는 단어는 예문이, 없는 단어는 예문 줄 없이 카드가 보인다. 결과 화면 목록도 같다.
9. 직접 쓴 단어를 내면 지금처럼 단어별 이모지가 보인다.
10. 닉네임, 게임, 결과 화면 모두에 출처 문구와 라이선스 링크가 보인다.
11. 단어장 데이터가 있는 곳에서 한국어기초사전 출처와 CC BY-SA 2.0 KR 라이선스를 확인할 수 있다.
12. [ai-wordchain-round](../ai-wordchain-round/spec.md)의 인수 기준 1–12(단어장 규모를 정한 13번은 이 스펙의 기준으로 대체)가 새 단어장에서도 통과한다.
13. 사전 단어가 기존 355개보다 크게 많다. 구체적인 최소 수는 "미룬 결정"에서 정한다.
14. 닉네임 화면에서 "시작하기"를 누른 뒤 첫 게임 화면이 1초 안에 나온다(가정의 로딩 기준).
15. 좁은 화면(약 400px 폭)에서도 출처 문구가 잘리거나 가로 스크롤을 만들지 않는다.

## 확정된 제약과 이유

- 단어는 한국어기초사전의 초급·중급 명사 2–4음절입니다. 난이도를 거르지 않으면 아이가 모르는 한자어와 전문 용어가 나와 "알기 쉽게 익힌다"는 목표를 해칩니다. 명사만 쓰면 끝말잇기의 일반적인 규칙과 같고 끝장단어 판정도 단순합니다.
- 기존 355개는 그대로 두고 겹치면 기존 항목을 씁니다. 아이 눈높이로 쓴 풀이와 이모지가 이미 있기 때문입니다.
- 사전 단어의 그림은 기본 아이콘이고, 예문은 사전 원문입니다. 새 단어 수천 개에 그림을 붙이는 것은 현실적이지 않고, 예문은 만드는 시점에 한 번만 받으면 됩니다.
- 게임 중에는 사전 서버를 부르지 않습니다. 서버 장애나 키 문제가 게임에 영향을 주지 않게 하기 위해서입니다.
- 한국어기초사전의 텍스트 자료는 크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 라이선스로 이용할 수 있습니다. 출처를 표시하고, 가공해서 만든 단어장 데이터는 같은 라이선스로 배포해야 합니다. 사전의 이미지와 소리 같은 멀티미디어는 파일마다 조건이 달라서 쓰지 않습니다.

## 가정 (바꿀 수 있는 선택)

사용자가 직접 정하지 않고 제가 정한 값입니다. 틀리면 이 문서를 고치고 다시 확인합니다.

- 한 단어에서 쓰는 뜻은 첫 번째 뜻이고, 예문은 그 뜻의 첫 번째 예문입니다.
- 사전 단어의 기본 아이콘은 📖입니다.
- 출처 문구는 모든 화면의 아래쪽에 한 줄로 둡니다.
- 제외 목록은 단어를 한 줄에 하나씩 적는 방식으로 관리합니다.
- 단어장 데이터는 앱 코드와 파일을 분리해서 둡니다. 사전에서 가져온 부분의 CC BY-SA 조건이 앱 코드로 번지지 않게 하려는 것입니다.
- 첫 게임 화면은 시작을 누른 뒤 1초 안에 나옵니다.

## 범위 밖과 이유

- 게임 중 사전 확인: 이번에는 내려받은 단어장에 없는 단어를 "사전에 없는 단어예요"로 처리합니다. 서버 장애가 게임에 영향을 주지 않게 하려고 뺐고, 별도 작업으로 다룹니다.
- 표준어 제안과 확인, 힌트(사전) 도우미: 기존 스펙에서 미룬 기능입니다.
- 사전 단어의 단어별 이모지: 필요해지면 흔한 단어부터 나중에 더합니다.
- 고급 단어, 다른 품사: 어려운 단어와 활용형 문제를 피하려는 것입니다.

## 미룬 결정

- **글자별 최소 단어 수:** 지금 한국어기초사전 서버가 열리지 않아 글자별 초급·중급 명사 수를 재지 못했습니다. 서버가 복구되면 흔한 첫 글자마다 필요한 단어 수를 확인해서 인수 기준 13에 최소 수를 정합니다.
- **난이도 필터의 정확한 형식:** 검색 API의 `level` 변수 형식을 확인하지 못했습니다. 안 되면 응답의 난이도 등급 값으로 직접 거릅니다.
- **단어가 부족할 때:** 초급과 중급만으로 모자라는 글자가 있으면 고급을 일부 넣을지는 데이터를 본 뒤 사용자가 정합니다.
- **아이에게 맞는지 검수하는 방법:** 만든 단어장에서 샘플을 뽑아 확인하는 방식과 제외 목록에 넣을 기준을 정해야 합니다.
- **AI의 끝장단어 확률:** 단어장이 커지면 끝장단어 비율과 판의 길이가 달라지므로, 데이터를 본 뒤 기존 50%를 다시 맞춥니다.

## 남은 위험

- 한국어기초사전 서버가 불안정하고 지금은 열리지 않아, 단어 수와 품질을 아직 확인하지 못했습니다.
- 초급·중급 명사가 아이에게 적당하지 않은 단어를 포함할 수 있습니다. 샘플 검수와 제외 목록으로 줄이지만 전수 검수는 하지 않습니다.
- 단어장 데이터가 커지면 앱 내려받는 크기와 시작 시간이 늘어납니다.
- 라이선스 해석: 동일조건변경허락이 단어장 데이터에만 적용되는지, 앱 코드까지 영향을 주는지는 확신이 없습니다. 법률 자문이 아니며, 필요하면 전문가에게 확인해야 합니다.
- Open API 호출 자체의 약관(호출 한도 외의 조건, 응답 저장 범위)을 확인하지 못했습니다.
- 개발 중 인증 키가 대화 기록에 노출되었으니, 한국어기초사전이 복구되면 키를 재발급해 `.env.local`을 바꿔야 합니다.
